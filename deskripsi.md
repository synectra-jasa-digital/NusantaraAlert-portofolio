<p><strong>NusantaraAlert</strong> adalah platform web pemantauan siaga bencana geofisika dan meteorologi publik terpadu di Indonesia yang menyajikan informasi kebencanaan secara real-time, interaktif, dan mudah diakses oleh masyarakat.</p>

<p>Indonesia berada di jalur Cincin Api Pasifik (Ring of Fire) yang sangat rawan terhadap bencana alam seperti gempa bumi, tsunami, dan cuaca ekstrem, namun akses masyarakat terhadap data kebencanaan real-time dan edukasi mitigasi sering kali terfragmentasi. NusantaraAlert menyelesaikan tantangan ini dengan mengintegrasikan data siaran langsung stasiun pemantau BMKG (TEWS) dan Open Data Meteorologi ke dalam satu antarmuka interaktif yang dilengkapi pemetaan episentrum, analisis risiko wilayah, asisten cerdas AI, serta dukungan akses offline saat kondisi darurat.</p>

<p>Fitur &amp; Alur Utama:</p>
<ul>
  <li><strong>Integrasi Live Data BMKG (TEWS):</strong> Menyajikan laporan gempa bumi terbaru (M 5.0+), skala intensitas MMI, kedalaman, koordinat, serta status evaluasi potensi tsunami secara otomatis dan real-time.</li>
  <li><strong>Peta Episentrum &amp; Overlay Sesar Aktif:</strong> Visualisasi peta interaktif berbasis Leaflet yang menampilkan episentrum gempa, jalur patahan geologi utama Indonesia, lokasi rumah sakit darurat, dan citra radar hujan.</li>
  <li><strong>Asisten AI Siaga Bencana ("Si Alerta"):</strong> Chatbot berbasis kecerdasan buatan yang siap menjawab pertanyaan seputar aktivitas seismik, prakiraan cuaca wilayah spesifik, serta panduan keselamatan darurat.</li>
  <li><strong>Indeks Risiko Bencana Daerah:</strong> Fitur analisis tingkat kerawanan bencana geofisika dan cuaca untuk lebih dari 500 kabupaten dan kota di seluruh Indonesia.</li>
  <li><strong>Prakiraan Cuaca &amp; Visualisasi 3D:</strong> Informasi kondisi atmosfer lengkap beserta visualisasi animasi dinamis untuk berbagai kondisi cuaca.</li>
  <li><strong>Panggilan Darurat Direct 24 Jam:</strong> Akses panggilan telepon bebas pulsa satu klik ke instansi tanggap darurat utama seperti Basarnas, BNPB, Ambulans, dan BMKG.</li>
  <li><strong>Progressive Web App (PWA) &amp; Offline Mode:</strong> Aplikasi dapat diinstal langsung di perangkat HP/Desktop dan menyimpan dokumen panduan mitigasi di memori cache agar tetap dapat diakses saat jaringan terputus.</li>
</ul>

<p>Tech Stack:</p>
<ul>
  <li><strong>Frontend Framework:</strong> React 18 &amp; Vite 5</li>
  <li><strong>Styling &amp; UI:</strong> Tailwind CSS 3, Vanilla CSS Animations, &amp; Lucide React Icons</li>
  <li><strong>Map &amp; Spatial Visualization:</strong> Leaflet.js &amp; React-Leaflet</li>
  <li><strong>API &amp; Data Feeds:</strong> BMKG TEWS API (autogempa, gempaterkini, gempadirasakan) &amp; Open-Meteo Weather API</li>
  <li><strong>PWA &amp; Offline Capability:</strong> Service Worker Custom &amp; Web App Manifest</li>
</ul>
